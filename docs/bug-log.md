# Bug log

Real bugs found in generated code while building Cutline. Date — what was wrong — how it was caught — the fix.

## Caught by tests

_None yet._ Every test failure during the build so far was in the test itself, not the code under test: a `-0` vs `0` deep-equal, and a figure test that measured the top of the head instead of eye height. Both tests were corrected, not the code.

## Caught outside the test suite

- 2026-10-27 — The program monitor rendered from the scene origin for the first shot after **Parse**. The camera pose was set in a `useLayoutEffect` through a ref, and drei's `<View>` mounts its children after that effect runs, so the ref was still `null`. — Caught by a headless-browser screenshot of the first frame. — Fix: pass `position`, `rotation` (order `YXZ`) and `fov` as props on `<PerspectiveCamera>` (`src/ui/MonitorView.tsx`).
- 2026-10-27 — Monitor lower label and PGM tally were invisible: the shared full-screen canvas painted over them. — Caught by the same screenshot check. — Fix: `z-10` on the overlays.
- 2026-10-27 — When a new speaker pair formed, the 180° side was computed against the *previous* pair's line (the helper read `this.line` before it was replaced). — Caught reading the code before the rule-4 tests ran. — Fix: `sideOf(camera, a, b)` takes the pair explicitly (`src/engine/index.ts`).
- 2026-10-27 — The LLM output schema used `z.enum` for row type and shot, assuming the API enforces it. Printing the SDK's generated JSON schema showed that enums become description hints, so a bad enum made the whole row fail parsing instead of nulling one field. — Caught by inspecting `zodOutputFormat` output. — Fix: the server schema checks structure only, and `validate()` nulls and flags the bad field. A test now covers it (`tests/server/app.test.ts`).
- 2026-10-27 — Armchair and sofa backrests were built on the front (−z) side, so seated figures faced into the backrest. — Caught reading the preset against the "models face −z" convention. — Fix: backrests at +z.
- 2026-10-27 — The Mixamo people stood in A-pose in front of their chairs: three.js's `GLTFLoader` strips the `:` from node names, so `mixamorig:Hips` arrived as `mixamorigHips` and the rig found no bones. — Caught by a browser screenshot after loading the models. — Fix: match `/^mixamorig:?/` (`src/ui/scene/models/rig.ts`).
- 2026-10-27 — Seated people had their thighs inside the armchair cushion: knees at 0.33 m against a cushion top at 0.405 m, because Mixamo's hip joints sit about 10 cm below the Hips bone. — Caught by the new rig test, which loads the real GLBs and measures knee and ankle heights (`tests/ui/rig.test.ts`). — Fix: hips at 0.55 m, thighs rising slightly toward the knees.
- 2026-10-27 — The "slow push in" and "slow zoom out" patterns never matched: the `\b` word boundaries were written through a Python string and landed in the file as backspace characters (U+0008). — Caught by the new test "pushes in over the shot on 'slow push in'", which saw an unchanged FOV. — Fix: real `\b` in `moveOf` (`src/show/index.ts`), and a check that no source file contains U+0008.
- 2026-10-27 — The people's squares on a shared screen were empty: the screen content had a z-index, so it painted above the shared 3D canvas and hid the iso views drawn there. — Caught by headless-browser frames of each screen kind. — Fix: the screen paints under the canvas (no z-index), and the studio feed is narrowed to the part of the frame the screen leaves (`screenWipe`), so the two never overlap.
- 2026-10-27 — Pasting a director's brief for Alex, Jamie and Sam gave "completely off" Jev results: every speaker red, and advice such as "maybe the screen should slide in" typed as visual cues that opened screens. Two causes: the studio stayed on Evening Desk (Anna, Mārtiņš, Laura), and the questions never asked whether a line is advice or a beat placed in the show. — Found by the author using the app; reproduced with Jev on the brief (71 segments). — Fix: the cast is read from the script in code and the studio is switched or recast (`src/classify/cast.ts`); two Noul questions (`general_advice`, `quote_is_line`) feed a truth table in `server/jev.ts`; quoted words become the dialogue text. Eval on the labelled rundowns unchanged (37/37).
- 2026-10-27 — Playback was slow (Show 30 fps, Plan 18 fps on an RTX 3060) because about 66 shader programs were linked every second. drei's `<Line>` rebuilds its geometry when its `points` array changes identity, and disposes its own material with it. The camera frustums made new arrays every frame, so the line shader was destroyed and relinked every frame in every view. — Found by profiling playback in headless Chrome and counting `linkProgram` calls (398 in 6 s). — Fix: frustums are `LineSegments2` objects whose buffer is rewritten in place (`Segments` in `markers.tsx`); the 180° line's points are memoised. Links during playback: 0.
